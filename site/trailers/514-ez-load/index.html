About the 514 EZ Load

Single-axle EZ Load with a powered deck that drops low, so mowers, golf carts and side-by-sides drive straight on.

Features

  • Powered EZ Load deck system, loading angle under 4°
  • 14' x 78" deck, 18" deck height
  • 5,000 lb rubber torsion axle
  • (4) D-rings with 20 mounting locations
  • Electric self-adjusting brakes
  • LED lighting
