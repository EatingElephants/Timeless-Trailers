About the 1424 Split Tilt

14K split tilt with the longer 18-foot tilt section and a 6-foot front deck: room for a skid steer with the attachment riding up front.

Features

  • 18' tilt deck + 6' stationary deck, 82-3/8" wide
  • 22" deck height, 11.5° loading angle
  • Tandem 7,000 lb rubber torsion axles
  • 18 stake pockets
  • Side crank jack, 12,000 lb
  • Adjustable 2-5/16" coupler
  • LED lighting
