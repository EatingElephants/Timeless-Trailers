# Working on this site

Clickable mock-up for Timeless Trailers (Timpte dealer, Waxhaw NC), client of Albright Agency. The owner (Josh) is not a coder: plain words, one clear action, double-click files over commands. See "Where we left off" in README.md.

- Edit `src/`, then `py -3 build.py` (Python at `C:/Users/jsalb/AppData/Local/Programs/Python/Python310/python.exe`). One build writes two sites: `site/` (public, no back end) and `site-demo/` (with the back end). Never hand-edit either `index.html`.
- **Two sites from one source.** `DEMO` is a build-time constant (`%%DEMO%%` in `src/app1.js`): `false` for `site/`, `true` for `site-demo/`. Code between `/* @demo */` and `/* @end-demo */` in `src/*.js` is cut out of the public build entirely, so anything that only the demo needs (sign-in, My Account, dealer console, personas, seed records, demo modals, their click cases and form handlers) goes inside a block, and the public code must never call it except behind `DEMO ?`. The build fails if markers don't pair or if back-end words survive in `site/index.html`. `site-demo/img|video|specs` are untracked links to `site/`'s copies; Cloudflare copies them with a build command (README, Hosting).
- Trailer specs in `src/data.js` `MODELS` are real, from Timpte's 2026 spec sheets. Don't invent numbers; the sheets are in `site/specs/`. Prices, stock and people are sample and labeled so.
- The assistant is Andy (`ASSISTANT_NAME`). The name has changed twice; keep it in that one constant.
- **Stammer is the only thing that answers customers.** Never add local answers, weights, tow ratings or fit verdicts to the customer side. `archive/local-matcher.js` is the old demo matcher, kept for reference only; don't load it. Every "Ask Andy" control calls `openChat(question)`.
- Anything priced or fictional (sample prices, personas, reviews, parts and service prices) must stay behind `DEMO` or inside a demo block. The public site says "Call for price". The 14 parts in `DATA.parts` are placeholders; Josh has a real parts page to supply.
- Approved exclusivity line: "The only dealer in the U.S. that sells Timpte equipment trailers exclusively" (short: "America's only Timpte-exclusive dealer"). Andy never quotes prices; the on-page line is `ANDY_LINE` in `src/app1.js`.
- Dealer-only Timpte documents (bulletins, order form, branding guide, priced parts catalog) are never published. `build.py` refuses them by file name.
- Photos: `tools/make_images.py` (Pillow). Videos: `tools/encode.ps1` (ffmpeg via winget, already installed). Every published file must stay under 25 MB.
- Preview: `timeless-v3` (public, 8766) and `timeless-demo` (demo, 8767) entries in the Albright repo's `.claude/launch.json`, or `preview.bat` / `preview-demo.bat`. After a rebuild, reload the page fully; a hash change alone keeps the old file.
- Hosting is Cloudflare Workers Builds from this GitHub repo: Worker `timeless-trailers` (`wrangler.jsonc`, `site/`) and Worker `timeless-trailers-demo` (`wrangler.demo.jsonc`, `site-demo/`). Holds, quotes and parts orders are browser-only state (localStorage); nothing is sent anywhere until Zoho (phase two).
